# SwitchedGames

> **Notice:** NARBE House, NARBE Foundation, SwitchedGames, and Benny's Hub are not affiliated with any cryptocurrency or crypto token. We accept donations only through official campaigns listed on our official websites.

This repository contains the SwitchedGames catalog and website. Game cards link to the games hosted in Benny's Hub; the game source, licenses and detailed credits live with each hosted game.

Benny’s Hub is the authoritative source for game thumbnails and launch paths, recorded in `bennyshub/apps/games/games.json`. Both the NARBE House and SwitchedGames indexes are showcases of that catalog. SwitchedGames cards, Details images and the hero poster use the published Hub image URLs directly; do not copy game thumbnails into this repository. Replace a thumbnail in the Hub to update every showcase that uses its canonical URL. Site-specific branding and switch-kit photography remain local.
